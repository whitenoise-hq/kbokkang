# 크보깡 — 앱 디자인 가이드 (토스 스타일)

> `apps/mobile`(Expo + RN)의 디자인 시스템. 어드민(`apps/admin`)은 shadcn/ui 사용, 이 가이드 대상 아님.
> **핵심 원칙: 모든 화면은 아래 디자인 토큰을 사용한다. 화면마다 즉흥적으로 스타일을 정하지 않는다.**
> 토큰은 `packages/shared`(또는 `apps/mobile/theme`)에 정의하고 전 화면에서 참조.

---

## 0. 토스 스타일 핵심 원칙
1. **넉넉한 여백.** 요소끼리 붙이지 않는다. 숨 쉬는 공간.
2. **한 화면 = 한 핵심 행동.** 복잡하면 단계로 쪼갠다(스텝 플로우).
3. **큼직하고 명확한 타이포.** 특히 숫자(포인트)는 크고 시원하게.
4. **절제된 색.** 무채색(화이트/그레이) 기반 + 포인트 컬러(파랑) 최소 사용.
5. **부드러움.** 둥근 모서리, 은은한 그림자, 부드러운 애니메이션.
6. **명확한 위계.** 제목 / 본문 / 보조 텍스트가 크기·색으로 확실히 구분.

---

## 1. 색상 팔레트 (Color Tokens)

### 메인 / 포인트
| 토큰 | 값 | 용도 |
|------|-----|------|
| primary | `#3182F6` | 메인 파랑(토스 톤). 주요 버튼, 강조, 활성 상태 |
| primaryPressed | `#1B64DA` | 버튼 눌림 |
| primaryLight | `#E8F1FD` | 파랑 배경(선택 영역 등) |

### 무채색 (기반)
| 토큰 | 값 | 용도 |
|------|-----|------|
| background | `#FFFFFF` | 기본 배경 |
| surface | `#F9FAFB` | 카드/섹션 배경 |
| border | `#E5E8EB` | 구분선, 테두리 |
| textStrong | `#191F28` | 제목, 강조 텍스트 |
| textNormal | `#4E5968` | 본문 |
| textAlt | `#8B95A1` | 보조/설명 텍스트 |
| textDisabled | `#C9CDD2` | 비활성 |

### 상태색
| 토큰 | 값 | 용도 |
|------|-----|------|
| success | `#00B26E` | 적중, 성공 |
| danger | `#F04452` | 실패, 경고, 포인트 차감 |
| warning | `#FFB020` | 집계중 등 대기 상태 |

### 카드 등급색 (등급 표현 전용 — UI 포인트 컬러와 구분)
| 등급 | 토큰 | 값 |
|------|------|-----|
| 일반 N | gradeNormal | `#8B95A1` (회색) |
| 레어 R | gradeRare | `#4A90D9` (등급용 파랑 — primary보다 차분) |
| 에픽 E | gradeEpic | `#9B51E0` (보라) |
| 레전드 L | gradeLegend | `#F2A900` (금) |
| 신화 M | gradeMythic | `#E03131` (빨강) |

> 주의: 등급색은 **카드·등급 표시에만** 사용. 일반 UI(버튼 등)엔 primary만.

## 2. 타이포그래피 (Type Scale)

| 토큰 | 크기/굵기 | 용도 |
|------|----------|------|
| display | 32 / Bold | 포인트 잔액, 큰 숫자 강조 |
| title1 | 24 / Bold | 화면 제목 |
| title2 | 20 / Bold | 섹션 제목 |
| body1 | 16 / Regular | 기본 본문 |
| body2 | 14 / Regular | 보조 본문 |
| caption | 12 / Regular | 설명, 라벨 |
| button | 16 / SemiBold | 버튼 텍스트 |

- 폰트: 시스템 기본(iOS SF / Android Roboto) 또는 Pretendard 권장(한글 가독성 좋음).
- 숫자 강조 시 tabular-nums 사용(자릿수 흔들림 방지).

---

## 3. 여백 / 간격 (Spacing) — 4px 단위
| 토큰 | 값 |
|------|-----|
| xs | 4 |
| sm | 8 |
| md | 16 |
| lg | 24 |
| xl | 32 |
| 2xl | 40 |

- 화면 좌우 기본 패딩: `md`(16) 이상. 여백 넉넉히.
- 섹션 간 간격: `lg`(24) 이상.

## 4. 모서리 둥글기 (Radius)
| 토큰 | 값 | 용도 |
|------|-----|------|
| sm | 8 | 작은 요소 |
| md | 12 | 버튼, 인풋 |
| lg | 16 | 카드, 모달 |
| full | 999 | 원형, 알약 버튼 |

## 5. 그림자 (Shadow)
- 은은하게. 진한 그림자 금지.
- 카드: `y=2, blur=8, rgba(0,0,0,0.06)` 수준.
- 떠 있는 버튼(FAB 등): 약간 더 강하게.

---

## 6. 컴포넌트 스타일

### 버튼
- 메인 버튼: 배경 primary, 텍스트 흰색, radius md, 높이 넉넉(52px 정도), 폭 넓게.
- 눌림 시 primaryPressed + 살짝 scale(0.98) 애니메이션.
- 보조 버튼: 배경 surface/투명, 텍스트 primary 또는 textNormal.

### 카드(경기·수집 카드 등 UI 컨테이너)
- 배경 surface 또는 white, radius lg, 은은한 그림자, 내부 패딩 md~lg.

### 입력/선택
- 큼직하게. 한 번에 하나씩. 선택 시 primaryLight 배경 + primary 테두리.

### 상태 배지
- 적중 success / 실패 danger / 집계중 warning / 마감 textAlt. 알약(full) 형태.

---

## 7. 애니메이션 (react-native-reanimated)
- 화면 전환: 부드러운 슬라이드/페이드.
- 버튼 탭: scale 0.98 + 살짝 눌리는 피드백.
- **뽑기 연출**: 카드 공개 시 긴장감 있는 연출.
  - 레전드/신화: 특별 연출(빛 번짐, 반짝임 오버레이). 등급색 활용.
- 숫자 변화(포인트 획득/차감): 카운트업/다운 애니메이션.
- 과하지 않게. 빠르고(200~300ms) 자연스럽게.

---

## 8. 화면별 적용 힌트
- **홈(예측)**: 오늘 경기를 큼직한 카드로 세로 나열. 마감 임박은 시간 강조. 한 경기씩 명확히.
- **뽑기**: 보유 포인트를 display 크기로 상단에 시원하게. 뽑기 버튼 큼직. 연출에 집중.
- **도감**: 그리드. 미보유는 회색 실루엣. 등급색으로 희소도 표현. 진행률 바.
- **마이**: 성적/포인트를 숫자 위주로 깔끔하게.

---

## 9. 금지 사항
- 화면마다 다른 색/폰트/여백 즉흥 사용 금지 → 반드시 토큰 참조.
- 등급색을 일반 UI에 남용 금지.
- 진한 그림자, 과한 애니메이션, 좁은 여백 금지(토스 감성 해침).
