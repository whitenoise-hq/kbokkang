# 크보깡 — 카드 이미지 생성 프롬프트 가이드

> 이 파일은 카드 이미지를 **일관된 화풍으로 대량 생성**하기 위한 프롬프트 모음이다.
> 파일 설명은 한국어, **실제 AI에 넣는 프롬프트는 영어**(품질·일관성 때문).
> 조합 방식: `[공통 스타일 앵커] + [종류 modifier] + [등급 modifier] + [개별 카드 내용]`

---

## 0. 사용 원칙 (중요)

1. **일관성이 최우선.** 카드가 150장이라도 한 세트처럼 보여야 함.
   - 가능하면 **레퍼런스 이미지 고정**(첫 완성 카드 1장을 기준으로 삼아 "이 스타일로"라고 지시).
   - 로컬 Stable Diffusion이면 같은 model/checkpoint + 같은 seed 계열 + LoRA로 고정.
   - GPT/Midjourney면 매번 공통 스타일 앵커를 앞에 붙이고, 레퍼런스 첨부.
2. **IP 금지.** 실존 선수/구단 로고/실제 유니폼 디자인 절대 사용 금지. `original fictional character`, `no logos`, `no team marks` 항상 포함.
3. **텍스트는 이미지에 넣지 않음.** 카드 이름/번호/등급은 앱에서 코드로 표시. 프롬프트에 `no text, no letters` 포함.
4. **비율 (중요, 실전 확인됨).** 카드는 **세로로 긴 직사각형**(3:4 또는 5:7). 정사각형 금지.
   - 비율은 **프롬프트가 아니라 생성 도구의 비율/해상도 설정에서 세로형(portrait)으로 지정해야** 실제로 적용됨. 프롬프트에만 적으면 안 먹힘.
   - GPT는 세로 비율 컨트롤이 약해 정사각형으로 잘 나옴 → 비율 정확히 잡으려면 PixAI/SD에서 portrait 설정 권장.
   - 프롬프트엔 보조로 구도 힌트(`vertical trading card composition, portrait orientation, character fitted within card frame`)를 추가.
   - 등급별 레이아웃:
     - 일반/레어/에픽 = **박스형**(캐릭터가 카드 안 프레임 영역에 담김, 배경 단순)
     - 레전드/신화 = **풀아트**(캐릭터+배경+이펙트가 카드 전체를 채움)
5. **등급 색 규칙(고정).** 일반=회색 / 레어=파랑 / 에픽=보라 / 레전드=금 / 신화=빨강(홀로그램 가미).

## 1. 공통 스타일 앵커 (Base Style Anchor)

> 모든 프롬프트 맨 앞에 붙인다. 화풍 통일의 핵심.

```
2.5-head SD chibi character, clean cel-shaded anime style, thick bold outlines, vibrant saturated colors, soft studio lighting, high detail, centered composition, vertical trading card composition, portrait orientation, character fitted within card frame, trading card game art, original fictional design (not resembling any real person or team), no logos, no team marks, no text, no letters
```

> **비율은 반드시 도구 설정에서 portrait(3:4 등)로 지정.** 위 프롬프트의 구도 힌트만으로는 비율이 확정되지 않음.

---

## 2. 종류별 Modifier (Type)

### 선수 (Player)

```
original fictional baseball player character, plain generic baseball uniform with no logos, dynamic baseball pose
```

포즈 변형 예시(개별 카드마다 하나 선택):

- 타자: `batting stance, swinging a wooden bat`
- 투수: `pitching throw pose, holding a baseball, motion lines`
- 포수: `catcher crouch pose, wearing catcher gear (generic)`
- 외야수: `diving catch pose with glove`
- 주자: `sprinting / sliding into base pose`

### 마스코트 (Mascot)

```
original fictional animal mascot character (bear / tiger / lion / eagle / dog etc, NOT any real team mascot), wearing a plain generic baseball uniform, cute friendly expression, holding baseball equipment
```

### 아이템 (Item)

```
baseball equipment object, no character, clean product-style illustration, centered single object
```

대상 변형 예시:

- `wooden baseball bat` / `leather baseball glove` / `baseball ball`
- `batting helmet` / `cheering stick` / `sports water bottle` / `baseball cleats`

## 3. 등급별 Modifier (Grade)

### 일반 (Normal) — 회색 / 박스형

```
framed boxed layout with simple plain background, muted gray-and-white color scheme, minimal effects, silver-gray border frame, clean and plain, calm mood
```

### 레어 (Rare) — 파랑 / 박스형

```
framed boxed layout, cool blue color scheme, subtle blue glow aura, light holographic blue accents, blue border frame, slightly dynamic
```

### 에픽 (Epic) — 보라 / 박스형

```
framed boxed layout, purple color scheme, glowing purple energy aura, sparks and light particles, ornate purple crystal border frame, dramatic and powerful mood
```

> 참고: 기존에 잘 나온 보라색 카드가 이 에픽 기준선. 이 느낌을 레퍼런스로 사용 권장.

### 레전드 (Legend) — 금 / 풀아트

```
FULL-ART layout filling the entire card, heroic epic pose, radiant golden aura, glowing light rays, floating golden sparkles and embers, luxurious gold ornate frame, majestic legendary presence, rich detailed background, cinematic lighting
```

### 신화 (Mythic) — 빨강 / 풀아트

```
FULL-ART layout filling the entire card, god-like mythical presence, intense crimson red color scheme, blazing red flames and fiery aura, glowing red energy, holographic red iridescent shine, embers and sparks, cosmic dark-red background, ultimate rarity, ornate glowing red border frame, breathtaking cinematic composition, ultra detailed masterpiece
```

## 7. 추천 도구 & 워크플로우

### 추천 도구

- **주력: PixAI** — 캐릭터 일관성(Reference Pro), 무료 50장/일, 세로 비율 설정 쉬움, 유료 $9.99~.
- **고등급(레전드/신화) 특별컷: Midjourney Niji** — 시네마틱 퀄리티(단, 일관성 약해 소수 카드에만).
- **완전 무료·무제한·최대 통제: 로컬 Stable Diffusion + Civitai 모델** — 세팅 부담 있으나 장기 대량 생산에 유리.
- GPT: 캐릭터 퀄은 좋으나 **세로 비율 컨트롤이 약함(정사각형으로 잘 나옴)**. 비율 중요한 카드엔 비권장.

### 핵심 워크플로우 (일관성)

1. **기준 카드 1장**을 먼저 완성(에픽 선수 등). 이게 전체 화풍의 기준.
2. 이후 모든 카드는 그 **기준 이미지를 레퍼런스로 물려주며** 생성(프롬프트만 같게 하는 걸론 부족).
3. 레퍼런스는 1~2개만(3개 이상은 화풍 뒤섞임).
4. 같은 모델/설정 유지.

## 8. 튜닝 메모 (작업하며 갱신)

### 화풍 기준 (확정)

- **화풍 방향 확정됨**: 2.5등신 SD, 셀셰이딩, 진한 아웃라인. (GPT로 일반 등급 타자 샘플 뽑아 확인 — 양호)
- 회색 톤 + 은색 프레임 + 심플 배경 = 일반 등급 레이아웃 정확히 나옴.

### 실전 교훈

- **비율 주의**: GPT 샘플에서 좋은 캐릭터가 정사각형으로 나옴 → 카드용으론 세로 비율 필수. 도구 설정에서 portrait 지정할 것.
- 손/배트 등 디테일은 양호하게 나옴.
